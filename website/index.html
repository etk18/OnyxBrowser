Setup Guide

Get up and running in 3 simple steps.

1

Install OnyxBrowser

Download the installer for your platform above. On macOS, drag OnyxBrowser to your Applications folder. On Windows, run the setup wizard.

2

Get an OpenRouter API Key

The AI agent requires an API key to function. Visit openrouter.ai, create a free account, and copy your API key.

3

Paste Key in Settings

Open OnyxBrowser → click ⚙️ Settings (top menu) → paste your OpenRouter API Key → click Save. You're ready to go!

💡
Pro Tip: Once your key is saved, open the AI sidebar (⚡ icon) and try: "Open YouTube and search for lofi music" — watch Onyx navigate autonomously!
